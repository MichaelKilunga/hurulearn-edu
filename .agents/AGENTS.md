# Project Rules - HuruLearn

## User Interface & Aesthetics
- **Bilingual & Human-Friendly Themes**: Default to clean, welcoming, and high-readability light/warm backgrounds (e.g. white, off-white, soft cream/slate) for school and student-facing interfaces. Avoid default dark/neon-heavy themes for Tanzanian educational platforms unless explicitly requested.
- **SMS Capability Preservation**: Do not remove SMS shortcode details (such as the 15054 shortcode and instructions) when refactoring layouts. Ensure SMS-based learning instructions remain clearly visible as a primary offline entry channel.
- **SMS Keyword Visibility**: The SMS keyword (`HURU`) and shortcode (`15054`) must always be clearly displayed on the homepage and on signup/login screens as a primary offline access method.
